# ScarpMap — Tool Lead Generation

> Mencari daftar usaha yang belum punya website di suatu kabupaten, lengkap dengan kontak dan media sosial, lalu diekspor ke Excel.

## ✨ Fitur

- Grid per kecamatan untuk menghindari batas 100 hasil
- Validasi website hidup / mati
- Prediksi lalu validasi handle Instagram
- Normalisasi nomor WhatsApp +62
- Ekspor ke Excel
- 8 modul Python

## 🛠 Tech Stack

"Python" "Playwright" "openpyxl" "Google Places" "OSM"

## 🚀 Menjalankan

```
pip install -r requirements.txt
python scarpmap.py --kabupaten "Jember"
```

## 📌 Catatan

Proyek ini merupakan bagian dari portofolio pribadi. Kode disusun untuk kebutuhan nyata,
bukan sekadar demo, sehingga sebagian konfigurasi spesifik lingkungan mungkin perlu
disesuaikan sebelum dijalankan.
